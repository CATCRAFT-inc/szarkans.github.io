# Зачарования

Кроме ванильных, на Кошкокрафте есть **свои зачарования**. Все они обычные: вешаются на столе зачарования и попадаются в сундуках и у торговцев — кроме проклятия, которое в столе не появится.

## Инструменты и оружие

| Название | Подходит | Что делает |
| -------- | -------- | ---------- |
| **Жадность** | кирки и прочий шахтёрский инструмент | Выпавший лут из блоков падает сразу в инвентарь. Не работает на блоки с инвентарём <span class="gray">(сундуки, воронки и т.д.)</span> |
| **Палач** | топоры | Убийство критическим ударом отрубает голову. С игроков — всегда; со скелетов, визеров, зомби, криперов, пиглинов и дракона — с шансом 8% |

## Тотем бессмертия

Отдельная ветка: все эти чары меняют то, что происходит **в момент срабатывания тотема**.

| Название | Что делает |
| -------- | ---------- |
| **Болванка** | Тотем не тратится, но и срабатывает не всегда — шанс растёт с уровнем зачарования |
| **Сдача** | Если тотем исчез после срабатывания, то возвращает зачарованную книгу с теми же чарами |
| **Активная защита** | Оглушает всех вокруг в радиусе 8 блоков |
| **Дымовая завеса** | Ослепляет всех поблизости на 5 секунд и телепортирует в случайное место неподалёку |
| **Посмертное возвращение** | Телепортирует в прошлое на 16 секунд |
| **Всем и каждому** | Базовые эффекты тотема распространяются на игроков поблизости |
| **Рыба** | Превращает в рыбу |

## Проклятия

| Название | Подходит | Что делает |
| -------- | -------- | ---------- |
| **Проклятие взрывоопасности** | на что угодно | Когда предмет ломается, он взрывается. На столе зачарования не появляется — только в сундуках и у торговцев |

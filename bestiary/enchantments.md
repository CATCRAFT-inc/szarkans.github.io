# Зачарования

Кроме ванильных, на Кошкокрафте есть **свои зачарования**. Все они обычные: вешаются на столе зачарования и попадаются в сундуках и у торговцев — кроме проклятия, которое в столе не появится.

## Инструменты и оружие

| Название | Подходит | Что делает |
| -------- | -------- | ---------- |
| **Жадность** | кирки и прочий шахтёрский инструмент | добытое летит сразу в инвентарь, минуя землю |
| **Палач** | топоры | критический удар отрубает голову. С игроков — всегда, с даты смерти на самой голове; со скелетов, визеров, зомби, криперов, пиглинов и дракона — с шансом 8% |
| **Резкость** | [крюк-кошка](/bestiary/custom_items/grappling_hook) | крюк начинает тянуть сразу, как зацепится, без паузы |

## Тотем бессмертия

Отдельная ветка: все эти чары меняют то, что происходит **в момент срабатывания тотема**.

| Название | Что делает |
| -------- | ---------- |
| **Болванка** | тотем не тратится, но и срабатывает не всегда — шанс растёт с уровнем зачарования |
| **Сдача** | после срабатывания возвращает зачарованную книгу с теми же чарами |
| **Активная защита** | оглушает всех вокруг в радиусе 8 блоков |
| **Дымовая завеса** | ослепляет всех поблизости на 5 секунд и перебрасывает тебя в случайное место неподалёку |
| **Посмертное возвращение** | возвращает туда, где ты был 16 секунд назад |
| **Всем и каждому** | раздаёт регенерацию, поглощение и огнестойкость игрокам рядом |
| **Рыба** | превращает тебя в лосося на 10 секунд — с водным дыханием и грацией дельфина |

## Проклятия

| Название | Подходит | Что делает |
| -------- | -------- | ---------- |
| **Проклятие взрывоопасности** | на что угодно | когда предмет ломается, он взрывается. На столе зачарования не появляется — только в сундуках и у торговцев |

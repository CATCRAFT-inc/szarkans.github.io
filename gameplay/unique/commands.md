# Команды в игре

::: tip Обозначения
`< >` - обязательное значение

`( )` - необязательное
:::

## Чат

| Команда | Что делает |
| :--- | :--- |
| `<сообщение>` | Локальный чат, **100 блоков** вокруг тебя |
| `!<сообщение>` | Глобальный чат - видит всё Кошкоземье |
| `~<сообщение>` | Шёпот, **10 блоков** |
| `#<сообщение>` | Клановый чат |
| `@ник` | Пингануть котика: ему звякнет и подсветится |
| `/msg <ник> <сообщение>` | Личное сообщение. Работают и `/pm`, `/tell`, `/w`, `/m` |

Ники в чате кликабельные: щёлкни по нику - подставится `/msg` этому котику. Щёлкни по самому сообщению - оно скопируется тебе в буфер.

## Действия

| Команда | Что делает |
| :--- | :--- |
| `/fart` | ... |
| `/suicide` | Умереть. |
| `/playtimetop` | Топ-10 по наигранным часам и строчка, на каком месте ты |
| `/playtimedays (ник) (дни)` | Сколько наиграно за последние дни. Без аргументов — твои за неделю |
| `/help <что случилось>` | Позвать [паладина Ордена Креста](/gameplay/unique/cross_order) — разобраться с обидчиком |
| `/rp` | Перезагрузить ресурспак сервера, если текстуры отвалились |

## РП-команды

| Команда | Что делает |
| :--- | :--- |
| `/me <действие>` | Описать действие персонажа<br><br>`/me погладил котика` -> `*Szarkan погладил котика` |
| `/do <описание>` | Описать что-то от третьего лица<br><br>`/do в зубах сигарета` -> `*В зубах сигарета (Szarkan)` |
| `/try <действие>` | То же, что `/me`, но с исходом: **Удача** или **Неудача**. |
| `/roll (число)` | Случайное число. Без аргумента кидает из 10, максимум - **100**<br><br>`/roll 20` -> `*Szarkan рольнул 12 из 20` |

## Плейсхолдеры

Плейсхолдер - это кусок текста, который в чате превращается в кликабельную штуку. Просто пиши его в сообщении, хоть посреди фразы.

| Плейсхолдер | Что делает |
| :--- | :--- |
| `[item]`, `[i]`, `[предмет]` | Показать предмет в руке - можно будет увидеть, книгу прочитать, карту посмотреть и т.п. |
| `[inv]` | Показать в чат свой инвентарь |
| `[ender]` или `[ec]` | Показать свой эндер-сундук |
| `[pos]` | Свои координаты и мир |
| `[ping]` | Свой пинг в миллисекундах |

## Котики+

Команды, которые есть только у [Котиков+](/info/donate).

| Команда | Что делает |
| :--- | :--- |
| `/hat` | Надеть предмет из руки на голову |
| `/tpa <ник>` | Попросить телепорт к котику |
| `/tpahere <ник>` | Попросить котика телепортироваться к тебе |
| `/tpaccept` | Принять запрос |
| `/tpdeny` | Отклонить запрос |
| `/tpacancel` | Отменить свой запрос |

::: warning Телепорт работает только между двумя Котиками+
Если у одного из вас Котика+ нет - телепорта не будет, ни в одну сторону.  
Зато сам телепорт мгновенный: ни ожидания, ни кулдауна.
:::

# Команды в игре

::: tip Обозначения
`< >` - обязательное значение

`( )` - необязательное
:::

## Чат

Пишешь просто так - тебя слышат котики в радиусе **100 блоков**. Хочешь дальше или тише - ставь символ в начало сообщения.

| Команда | Что делает |
| :--- | :--- |
| `<сообщение>` | Локальный чат, **100 блоков** вокруг тебя |
| `!<сообщение>` | Глобальный чат - видит весь сервер |
| `~<сообщение>` | Шёпот, **10 блоков**. Для тех, кто рядом |
| `#<сообщение>` | Клановый чат. Если клана нет - сообщение улетит в глобал, тебя предупредят |
| `@ник` | Пингануть котика: ему звякнет и подсветится. Подряд можно 5 раз, потом 10 секунд перерыв |
| `/msg <ник> <сообщение>` | Личное сообщение. Работают и `/pm`, `/tell`, `/w`, `/m` |

Ники в чате кликабельные: щёлкни по нику - подставится `/msg` этому котику. Щёлкни по самому сообщению - оно скопируется тебе в буфер.

## Действия

| Команда | Что делает |
| :--- | :--- |
| `/emoji (эмодзи)` или `/e` | Пузырь с эмодзи над головой. Всего их три; без аргумента откроется выбор |
| `/fart` | Пёрнуть. Со звуком и облачком |
| `/suicide` | Умереть. Первый ввод только предупредит, второй - убьёт |
| `/playtimetop` | Топ-10 по наигранным часам и строчка, на каком месте ты |
| `/rp` | Перезагрузить ресурспак сервера, если текстуры отвалились |

## РП-команды

| Команда | Что делает |
| :--- | :--- |
| `/me <действие>` | Описать действие персонажа<br><br>`/me погладил котика` -> `*Szarkan погладил котика` |
| `/do <описание>` | Описать что-то от третьего лица<br><br>`/do в зубах сигарета` -> `*В зубах сигарета (Szarkan)` |
| `/try <действие>` | То же, что `/me`, но с исходом: **Удача** или **Неудача**. Решает сервер, не ты |
| `/roll (число)` | Случайное число. Без аргумента кидает из 10, максимум - **100**<br><br>`/roll 20` -> `*Szarkan рольнул 12 из 20` |

Все четыре видны в радиусе **40 блоков**.

## Плейсхолдеры

Плейсхолдер - это кусок текста, который в чате превращается в кликабельную штуку. Просто пиши его в сообщении, хоть посреди фразы.

| Плейсхолдер | Что делает |
| :--- | :--- |
| `[item]`, `[i]`, `[предмет]` | Показать предмет в руке. Карту разглядят, зачарования увидят. С пустой рукой отругает |
| `[inv]` | Показать свой инвентарь целиком |
| `[ender]` или `[ec]` | Показать свой эндер-сундук |
| `[pos]` | Свои координаты и мир. Кулдаун 5 секунд |
| `[ping]` | Свой пинг в миллисекундах. Кулдаун 5 секунд |

Всё это работает и в личных сообщениях - можно скинуть котику предмет на оценку без свидетелей.

## Котики+

Команды, которые есть только у обладателей [Котика+](/info/donate).

| Команда | Что делает |
| :--- | :--- |
| `/hat` | Надеть предмет из руки на голову |
| `/tpa <ник>` | Попросить телепорт к котику |
| `/tpahere <ник>` | Попросить котика телепортироваться к тебе |
| `/tpaccept` | Принять запрос |
| `/tpdeny` | Отклонить запрос |
| `/tpacancel` | Отменить свой запрос |

::: warning Телепорт работает только между двумя Котиками+
Право на запрос и право на приём есть только у доната. Если у одного из вас Котика+ нет - телепорта не будет, ни в одну сторону.
:::

Зато сам телепорт мгновенный: ни ожидания, ни кулдауна.

### Что Котик+ даёт без всяких команд

- **Ежедневный кит** - приходит почтой сам, раз в сутки при заходе на сервер.
- **Кошелёк без лимита**. У обычного котика в кошелёк влезает 156 мурок, у тебя - сколько угодно.
- **Последние 9 слотов эндер-сундука открыты**. У остальных они заткнуты заглушкой.
- **Посылка в почте вмещает вдвое больше**.
